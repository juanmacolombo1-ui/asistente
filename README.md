# Asistente personal

Web app de tareas, hábitos y recordatorios con turnos rotativos (mañana/tarde). Funciona sin conexión; los datos quedan solo en el teléfono.

- Abrila en Safari en el iPhone → Compartir → «Agregar a pantalla de inicio».
- Cada vez que la abras, tocá 🔇 para activar sonido y voz.
- Para que suene con el teléfono bloqueado: Agenda → «📅 Al Calendario».
- Más → Permisos y límites explica qué funciona en tu equipo.

Código sin dependencias: HTML, CSS y JavaScript (módulos ES). Para publicar cambios, subí el número de `VERSION` en `sw.js`.
